# コンセプト

- ユーザーが欲しい機能を入れたOS
- 私が学んできた技術を全て詰め込んだOS


- 複数の独立したNOSを1つのカーネルで実行する構造。
- システムコールレベルで隔離されていて、1つがやられても続けて動作させる。
- NOSには異なる機能を入れている
- - NOS      :ユーザーが操作する部分
- - DriverOS :IOを制御する部分
- - VOS      :仮想マシンやアーキテクチャの違うを回収する部分
- カスタマイズ性を高めたOSエンジン
- 少ないリソースで動作するOS

# 入れる機能
- windows/linux完全互換
- 専用コードでGUIカスタマイズ
- dockerもどき
- カーネル最適化モード（できる限り1つのタスクにリソースを集中させる）
- 他アーキテクチャ互換機能
- 軽量化ソフト
- OSシステムファイルクリーナー
- わかりやすい説明文(エンジニアでもない人が理解できるように)
